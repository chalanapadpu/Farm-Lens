# 🌱 FarmLens AI

### Empowering Farmers. Connecting Markets. Growing Together.

FarmLens AI is a digital marketplace prototype designed to connect marginal farmers directly with buyers. It helps farmers showcase their agricultural produce and enables buyers to explore available products, compare prices, and search by category and location.

## 🎯 Problem Statement

**PS 1.2 — Direct Market-Access Platform for Marginal Farmers**

Marginal farmers may face challenges reaching buyers directly, accessing market information, and showcasing their produce to a wider audience. Dependence on intermediaries can also limit their market opportunities.

## 💡 Our Solution

FarmLens AI aims to make agricultural market access simpler through a user-friendly digital platform.

### ✨ Features

- 🌾 Add agricultural produce listings.
- 🔍 Search available produce.
- 📍 Filter produce by location.
- 🥬 Browse produce by category.
- 💰 Sort listings by price.
- 📦 Display produce prices and quantities.
- 🤝 Support direct contact between farmers and buyers where contact details are available.
- 💻 Responsive interface for convenient access.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.

## 🧪 Project Status

FarmLens AI is a hackathon prototype. Produce listings are currently stored in browser Local Storage. A shared database, user authentication, verified market prices, and additional language support can be considered for future development.

## 🌍 Expected Impact

- Improve visibility for marginal farmers.
- Help buyers discover locally available produce.
- Encourage transparent price comparisons.
- Support more accessible digital agricultural marketplaces.

## 🔮 Future Enhancements

- Shared online database and farmer accounts.
- Regional language support.
- Verified market price information.
- Buyer enquiries and order management.
- Farmer cooperatives and logistics integration.
